# 21 — Glossary

| Term | Meaning |
|---|---|
| ACID | Atomicity, Consistency, Isolation, Durability — DB transaction guarantees |
| AP / AR | Accounts Payable / Receivable |
| BOM | Bill of Materials — components needed to make an item |
| CoA | Chart of Accounts |
| COGS | Cost of Goods Sold |
| GL | General Ledger |
| GRNI | Goods Received Not Invoiced (accrual account) |
| Journal entry | Balanced set of debit/credit lines |
| MoSCoW | Must / Should / Could / Won't prioritisation |
| MRP | Material Requirements Planning |
| RBAC | Role-Based Access Control |
| RLS | Row-Level Security (SQL Server feature) |
| SaaS | Software as a Service — vendor hosts and operates the app |
| PaaS | Platform as a Service — vendor provides a platform to build apps on |
| Tenant | One customer company and its isolated data |
| UoM | Unit of Measure |
| PII | Personally Identifiable Information |
| STRIDE | Spoofing, Tampering, Repudiation, Info disclosure, DoS, Elevation of privilege |
| TDE | Transparent Data Encryption |
| DPA | Data Privacy Act (PH) / Data Processing Agreement (context-dependent) |
| WIP | Work in Progress |
| WAvg | Weighted-average costing |
| BA / PO | Business Analyst / Product Owner |
